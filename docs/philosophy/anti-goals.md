# Anti-goals

One More Timeline is not intended to be:

- a permanently increasing number with no meaningful decisions;
- a slot-machine loop disguised as progression;
- a service that requires a social graph, continuous presence, or paid urgency;
- a system that hides critical rules behind opaque automation;
- a competitive environment that rewards spending, speed, or harassment;
- a general-purpose scripting platform for arbitrary executable content;
- a promise that a documented contract is already implemented;
- a substitute for the player's judgement, consent, or control over their data.

These anti-goals constrain future features. A feature that conflicts with one MUST be rejected or redesigned before implementation.
